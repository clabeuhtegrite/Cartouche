# 108. Cartouche Builder says what stops a build before it starts

2026-11-14

Cartouche Builder says what stops a build before it starts, and leaves aside the games no Mac built ([#192](https://github.com/clabeuhtegrite/Cartouche/pull/192)). An Xcode older than the one nxnative builds the shaders with (its `dm/gfx/tools/own_compilers.py` names 27.2) stops a batch before its first game, and **This Mac's tools** offers **Update Xcode**; nxnative's refusal of the Mac's Metal compiler is a cause of its own, `metal`, said with both versions, which skips the game instead of failing it. When the build folders' disk has less room than **Keep at least … GB free**, the library says before a build how many gigabytes are missing and what makes room; a game of the batch that ended leaves its build folder to the games after it; `builder.skipped` sends the gigabytes free and needed. Each Thursday, the nxnative page workflow also writes `unbuilt.json`: the games at least three Macs tried in 28 days without any building one, forks of nxnative left out, with how many Macs and builds, how long, and the step most failed at, each from three Macs or more. A game on it, never built on the Mac, says so on its sheet, building it asks first, and the nightly run leaves it aside.

**Why.** The telemetry tour of 14 November. Ocarina of Time's update failed eight times on one Mac, read as damaged files: it was nxnative refusing Xcode 27.1's Metal compiler, which the player could not tell from the error, and the same Mac built it later that day with nxnative's Metal lock unchanged. 19 games were skipped for room on 7 Macs, 10 of them after Pokémon Pokopia's failed build folder in the same batch, without saying how much room there was or what to do. Pokopia failed eight times on four Macs, after up to eight hours, and no Mac built it, each time in a build the player asked for: the question before a build is what stops the next one, and the nightly run's leaving it aside keeps it from coming back at night. A list of three Macs or more names no Mac and no player ([decision 35](../decisions.md)), and nothing more is sent to know it.
