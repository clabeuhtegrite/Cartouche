# 93. A save exported on the player's Switch continues the game in Cartouche, and goes back as a ZIP for JKSV

2026-11-13

A game's sheet, under **Saves**, has **Switch saves**: the save the player exported on their own Switch with JKSV or Checkpoint, a folder or a ZIP archive picked in Files, comes in place of the game's save on this iPhone after a question, and the game's save goes into a ZIP archive that JKSV restores on the Switch ([`CartoucheSwitchSave.swift`](../../launcher/Sources/CartoucheSwitchSave.swift), [`CartoucheSwitchSaveView.swift`](../../launcher/Sources/CartoucheSwitchSaveView.swift)). Nothing is converted: nxnative keeps a game's save as the Switch does, the files the game wrote under the same names, in its `Documents/save`, or `save_device` for the console's save of a game that mounts both. JKSV's fiche (`.nx_save_meta.bin`) is read: the game's title ID must be the game's or one of its regions', and the save a player's or the console's; system, BCAT, temporary and cache data are refused. A save without the fiche, as Checkpoint exports one, is taken for a player's, of the game whose title ID its folder's name gives, if any. Refused too: more than one save, a path that would leave the save, a link, two names the iPhone cannot keep apart, a console's save for a game that never started, and anything while the game runs or while nxnative has not finished bringing in its cloud save. The save replaced is kept first, in `save-backups/<date> before import`, beside nxnative's own backups, which nxnative leaves alone, and **Put back** brings it back; what nxnative left of its working copies goes; the save that came is dated at the import, so that Cartouche's sync and nxnative's cloud saves send it on as the newest. Every save comes from the player's own Switch: Cartouche never hosts nor downloads one, as it never does games, keys or firmware ([decision 1](../decisions.md)).

**Why.** The owner chose this among the next works and asked for both ways (2026-11-13): a player who owns a game on the Switch wants to continue it on the iPhone, and back. JKSV and Checkpoint are what players use to export a save from their own console; nxnative's save is the Switch's, file for file (`hle_fs.c`), so no tool or format stands between them. No public tool exports a Switch 2 game's save yet, which the page says.
