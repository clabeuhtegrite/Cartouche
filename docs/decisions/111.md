# 111. Cartouche moves to an organization for GitHub's Macs, and keeps its addresses

2026-11-14

The repository moves from Ad's account, clabeuhtegrite, to an organization of its own on GitHub Enterprise Cloud, where GitHub runs 50 macOS jobs at a time rather than 5, on its standard runners, which stay free for a public repository. What Cartouche and the Cartouche Installers already given out read stays at the first owner's addresses, which GitHub redirects to the repository's new place: the source of Cartouche's updates (`CARTOUCHE_SIDESTORE_SOURCE_URL` in [config.env](../../app/config.env)), and in it the address of each release's IPA, which the [Release workflow](../../.github/workflows/release.yml) writes under `clabeuhtegrite/Cartouche` wherever the repository lives, as an Installer takes an IPA from there alone. What reads GitHub's own answers follows the repository where it is: Cartouche Builder takes its updates from the releases of the repository GitHub answered for ([Updater.swift](../../builder/mac/Sources/BuilderKit/Updater.swift)), and the site its download links from those of `GITHUB_REPOSITORY` ([downloads.py](../../site/tools/downloads.py)). The private repository of the players' problems, `clabeuhtegrite/cartouche-reports`, stays on Ad's account. No repository is made again at the old name, which would end GitHub's redirects.

**Why.** Since pull requests merge without waiting for their turn (2026-11-14), the Macs are what they wait for: over the 24 hours to 18:30 UTC on 14 November, 341 Mac jobs ran, 110 to 130 hours of Mac time, and up to 53 jobs waited or ran at once for 7 places, GitHub's 5 and the 2 of Ad's Mac, so that a job waited up to two hours in the evening. Ad chose Enterprise, $21 a month (2026-11-14), over GitHub's Macs with Macs rented by the minute for the peaks, about $3,700 a month from services that do not offer Xcode 27.2 yet, and over a Mac rented by the month, one place more. GitHub redirects a moved repository's pages, git, raw files and API, but not its Pages site, and its API then answers with the new place's addresses. Cartouche's built-in SideStore reads its source at the address Cartouche was built with, and the Installers given out check the IPA's address against the first owner's: keeping both keeps every iPhone and every Installer updating.
