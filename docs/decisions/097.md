# 97. What's new after an update, once, in the player's language

2026-11-13

After an update, however it came, Cartouche opens on **What's new**: the release notes of the version installed, the ones `app/releases/<version>.md` gives in English and `<version>.fr.md` in French, which the app carries, shown once over the console until the player closes them, then on the System page with those of the last ten versions ([`CartoucheReleaseNotes.swift`](../../launcher/Sources/CartoucheReleaseNotes.swift), [`CartoucheWhatsNewView.swift`](../../launcher/Sources/CartoucheWhatsNewView.swift)). Never on a first install; after an update over several versions, the notes of each since the last ones seen, the newest three at most; nothing for a version without its own notes. The version whose notes were seen is kept in the preferences; the first version with What's new tells an update from a first install by what an older Cartouche left there, its guide or an update it started. Every version from 0.12.2 on has its French notes ([`test_release_notes.py`](../../app/tests/test_release_notes.py)). On an iPad, the notes call it the iPad, as the launcher's words do ([decision 91](../decisions.md)).

**Why.** Ad asked for it on 2026-11-13. The notes are those the releases already publish, so nothing new to write but their French, and the app needs no network to show them, nor the source, which keeps only the last ten versions and only in English. A record of the version seen survives an update and goes with a deleted app, which is a new install. What tells the first update apart, the guide's preferences, which Cartouche writes once the guide has opened or the player has a game, and the version an update from Cartouche leaves, are absent on a new install, unlike the player's storage, which the keychain brings back.
