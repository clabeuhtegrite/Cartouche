Games nxnative built without their game files now install with the romfs.img beside them, and Google Drive joins your storage.

- Games: an nxnative IPA built without its game files installs with the romfs.img beside it in your games folder. Cartouche checks the image against the IPA before it unpacks anything, copies it into the game and keeps it across the game's updates. The storage page says which games lack their image, instead of finding no game.
- Storage: Google Drive, through an OAuth client of the iOS type that you make in your own Google Cloud project, with a step-by-step guide: Cartouche ships no Google key. A project left in testing asks you to sign in again every 7 days, and Cartouche then offers Sign in to Google again, without an error.
- Storage: an SMB server no longer hangs up when two requests leave at once on one connection, and an install from a shared folder keeps its memory.
- Installs: an install, or a copy to your games folder, goes on after you leave Cartouche, with its progress in a Live Activity whose stop button stops it.
- Installs: an IPA from Files that is damaged or cut short is refused, with nothing installed, and Cartouche says to copy it again; so is a zip with no app in a Payload folder, and an app whose Info.plist cannot be read, instead of an app named Unknown.
- Import a game opens one Files picker over whatever is on screen, which B closes: Cartouche no longer freezes there.
- Games: a game Cartouche does not know takes its platform from its ID, and its cover and genre from IGDB. Edit the game's info changes any game's name, platform, genre, description or cover, from Photos or Files, on this iPhone only.
- Games: each game's sheet shows its description under its name, IGDB's summary or your own. On iOS 18 and later, the iPhone translates IGDB's summary into Cartouche's language itself, with Translate when the languages are not downloaded yet, and Show the original.
- Games: a game behind the console turns only as its own app allows, so a game made for landscape stays in landscape.
- Games: on an iPhone whose graphics cannot read the textures of nxnative's games, the A16's and older, an install asks first, and the game's sheet and the System page say why. When a game's process behind the console lacks Increased Memory Limit, games start in Cartouche's place.
- Apple ID: when Apple refuses more sign-ins for a while, Cartouche says so and counts the wait down before signing in again. It checks that it reaches the iPhone before anything goes to Apple, and Register this iPhone takes that step alone, by itself once LocalDevVPN connects. A sign-in that stopped before the certificate no longer reads as signed in: Cartouche says why, with Copy the report and Sign in again, and signs in again by itself once after it is installed again.
- Renewal: Cartouche renews itself alone, even when another SideStore of the same Apple ID lists other apps, and reads its expiry again when SideStore stops on the way.
- Your own certificate: the new Cartouche Installer can install Cartouche signed with your own signing certificate (.p12) and its provisioning profile, without an Apple ID, LocalDevVPN or a renewal each week. Games then start in Cartouche's place, and most of them do not start without Increased Memory Limit in the profile. The Apple ID stays the default. Thanks to javi11.
- The iPhone can lock again after a game failed to start behind the console.
- Measurements: a game's frame rate leaves out its pauses, behind the console or with Cartouche in the background; each session's memory goes with the game that ran it; turning measurements off also stops a report on its way; SideStore's errors say what is behind them.
- Mac: Cartouche Builder 0.5.0 imports an nxnative IPA with its romfs.img, builds a game from the last nxnative commit that built when the newest does not, and says why a game was not built. It updates itself to it.
