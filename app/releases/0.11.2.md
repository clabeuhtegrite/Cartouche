Signing in with your Apple ID should go through now, as it does with the Cartouche Installer.

- Apple ID: since October, Apple refuses a sign-in that says it comes from one kind of computer while its sign-in data comes from another, and Cartouche stopped with -80045, -80046 after the code, or -45061 "reprovision required", which installing Cartouche again did not fix. Cartouche now signs in the way the Cartouche Installer does, which Apple accepts for the same accounts, and starts afresh by itself when a sign-in server or Apple refuses it.
- If Cartouche never got past its Apple ID step, it cannot update itself: install this version with the Cartouche Installer, then sign in again.
- An Apple ID signed in already keeps its current way until it signs in again, and its renewals go on as before.
- Measurements: an error with the sign-in servers counts as theirs, and an iPhone with no connection counts as offline first.
