Cartouche offers to update a game when your games folder holds a newer build of it.

- Games: when your games folder holds a newer IPA of a game you installed, a later version of the game, or the same version built again from a newer nxnative, such as one Cartouche Builder made, the console shows Update for the game and a badge on its cartridge, and its sheet Update from your games folder. The game's settings and saves stay.
- Games: a game's sheet shows which build of it is on this iPhone, and the newer one in your games folder: its version, the nxnative commit it was built from and when it was built.
- Games: a copy Cartouche writes of a game to your games folder keeps when the game was built, so that it is never offered as an update over the same game.
