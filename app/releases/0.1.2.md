Install it with iloader, from scratch or over 0.1.1: nothing to set in SideStore or anywhere else.

- iloader: in Manage Pairing File, Place In All Apps now puts the pairing file into Cartouche, listed there as LiveContainer. No export, no AirDrop. Cartouche keeps its name on the home screen.
- Setup: the pairing file step ticks itself, even while you are still at the computer. Sign in with SideStore opens LocalDevVPN, then the Apple ID sign-in, and brings you back to Cartouche once you are signed in.
- The built-in SideStore signs in through the SideStore (New) anisette server, as iloader does, no longer asks for a pairing file it already has, and accepts the one iloader exports.
- A pairing file exported from iloader can also be opened with Cartouche, from AirDrop or Files.
