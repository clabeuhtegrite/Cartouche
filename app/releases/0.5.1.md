Games start again after an install from another computer.

- Games: when the Cartouche Installer, run from another computer, revoked the old certificate, games no longer started ("the app is signed with the latest certificate but its signature is invalid"). Cartouche now checks that iOS accepts the certificate games are signed with, and if not, signs in again with your Apple ID by itself to take the new one. It asks you only should Apple want a verification code.
- Updates: Cartouche offers none while its certificate does not work, since an update signed with a revoked certificate would not open.
- Install this version with the Cartouche Installer if a game shows that message: an update from inside Cartouche would be signed with the revoked certificate.
