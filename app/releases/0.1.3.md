Install it with iloader, from scratch or over 0.1.2.

- Pairing file: in iloader, Manage Pairing File › Export, then drop the file on Cartouche in Apple Devices, iTunes or the Finder (Files). Cartouche takes it by itself and the setup step ticks, with no tap on the iPhone.
- 0.1.2 said that iloader's Place In All Apps lists Cartouche as LiveContainer. It does not: iloader reads the name in the iPhone's language, Cartouche. The setup now says to export the file.
- A pairing file opened with Cartouche from AirDrop, Mail or Files, or chosen in the setup, still works.
